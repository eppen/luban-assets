# Luban assets

Public image assets for the [Luban](https://github.com/eppen/luban) VS Code / VSCodium extension, kept in a separate public repository because the source repository is private while the extension listing and its README are public.

## Contents

| File | Shows |
|---|---|
| `screenshots/panel.png` | The Luban chat panel in the side bar next to an editor with inline diff |
| `screenshots/review.png` | A review diff with per-hunk accept / undo CodeLens and the diff title-bar actions |

These images are referenced from the extension's `README.md` and `README.zh.md` via their `raw.githubusercontent.com` URLs. They contain UI screenshots of a demo workspace only — no API keys, private paths, or personal data.
